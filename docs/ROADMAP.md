# Roadmap

## Phase 0：基础设施

- Folder Structure
- AGENTS.md
- 文档目录
- TypeScript strict
- Lint
- Build
- 基础 CI

## Phase 1：Onboarding

- 登录入口
- 创建 FixedSchedule
- 固定计划确认
- Profile 设置
- Onboarding 进度保存

## Phase 2：推荐

- 规则型过滤
- 推荐排序
- 推荐列表
- 用户 Profile
- 位置模糊显示

## Phase 3：连接与聊天

- 打招呼
- 创建 Conversation
- 一对一文字聊天
- 消息发送失败重试

## Phase 4：Invitation

- 创建
- 接受
- 拒绝
- 撤回
- 防重复提交
- 状态机测试

## Phase 5：Meetup

- accepted Invitation 创建 Meetup
- Meetup Detail
- 精确地点权限
- 取消
- 提醒
- 活动后反馈

## Phase 6：安全

- Block
- Report
- 社交安全规则
- 日志脱敏

## Phase 7：地区活动

核心个人同行流程稳定后，再考虑：

- 地区活动
- 活动报名
- 自动分组
- 群组聊天

## 暂缓功能

第一版不开发：

- 持续 GPS
- 实时位置共享
- 语音和视频
- 图片聊天
- 已读状态
- 动态社区
- 公开评论
- 复杂 AI 推荐
- 积分和等级
- 复杂会员系统
